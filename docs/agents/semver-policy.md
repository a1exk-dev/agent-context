# Semver policy

- Production branch: main
- Development branch: develop
- Hotfix branches: on
- Tag prefix: v
- Development merge: squash
- Production merge: merge commit
- Finish mode: pull request
- Tag and back-merge: CI
- Back-merge conflicts: confirm
- Development auto-merge: on
- Production auto-merge: off
- Finish approval: automatic
- Breaking before 1.0.0: minor
- Breaking definition: Skill names, Rule names, Setting names and values, Policy file names and formats
